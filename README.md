# wakamex/scoop-bucket

[Scoop](https://scoop.sh/) bucket for Windows packages published by `wakamex`. Each manifest points to an immutable GitHub Release archive and its `SHA256SUMS` digest.

## Usage

```powershell
scoop bucket add wakamex https://github.com/wakamex/scoop-bucket
scoop install wakamex/wakterm
```
